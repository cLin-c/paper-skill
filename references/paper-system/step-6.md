# 第6步 · 翻译排版

[返回八步工作流](../../workflows/paper-system-eight-steps.md)

先应用工作流中的执行约定，再按本次任务选择提示词。以下保留来源编号与正文；本机路径已替换为填写项。具体模型、项目、刊会和数量是案例条件，应按当前材料调整。

## 阶段任务与交付

这一步做什么：把核查后的中文稿翻译为英文，并装入目标刊会的排版模板。

1. 统一专业术语，逐段翻译并回查含义、数据、结论强度和引用。
2. 选择并核实目标刊会当前适用模板，将正文、公式、表格、引用与附录迁入Word或LaTeX。
3. 生成可阅读的英文初排版稿，检查编译、公式、交叉引用与文件完整性。

应产出的材料：英文完整初稿、中英术语对照、模板工程和首版排版PDF。

完成标准：译文忠实于中文稿，公式与引用无遗漏，排版工程可正常打开或编译。

## 6.4 公式与变量规范化

来源编号：`prompt-15`

```text
请检查论文中的公式、变量和符号规范。

要求：
1. 变量使用斜体；
2. 函数名、算子、常量和缩写使用正体；
3. 上下标尽量简洁，不使用英文单词式下标；
4. 同一个变量全文含义一致；
5. 图、正文、算法和表格中的符号保持一致；
6. 给出“原符号 / 建议符号 / 修改位置 / 修改原因”表格；
7. 公式输出为可编辑LaTeX，并说明在Word或Overleaf中如何替换。
```

## 6.5 可编辑公式、变量与下标统一

来源编号：`prompt-42`

```text
请检查并规范文档中的全部公式和变量。

要求：
1. 所有公式使用Word原生公式或目标文件支持的可编辑公式，不得以图片、乱码或LaTeX源代码正文代替；
2. 变量必须先定义后使用，标量、向量、矩阵和坐标系采用一致的字体规则；
3. 变量下标优先使用含义明确的单字母，禁止同一变量在不同位置表示不同含义；
4. 检查矩阵维度、乘法顺序、转置、上下标和坐标变换方向；
5. 正文变量、公式、伪代码、图表和算法流程保持一致；
6. 修改公式后同步更新变量定义、方法描述、实验设置和结论；
7. 保持公式编号和交叉引用正确。

请列出每处问题、正确形式及同步修改位置，并生成格式完整的修改版文件。
```
