# 第3步 · 根据故事线完成所有实验

[返回八步工作流](../../workflows/paper-system-eight-steps.md)

先应用工作流中的执行约定，再按本次任务选择提示词。以下保留来源编号与正文；本机路径已替换为填写项。具体模型、项目、刊会和数量是案例条件，应按当前材料调整。

## 阶段任务与交付

这一步做什么：逐项补齐支撑全文贡献所需的证据，明确方法为何有效、何时失效。

1. 按每项主张制定实验清单，安排必要的主实验、公平对比、消融、鲁棒性、泛化与效率分析。
2. 研究不同方法、模块、变量带来的增益与影响，检查边界条件和失败案例。
3. 完成数据统计、原始文件归档与复现细节整理，逐项核对主张、表格、日志与结论。

应产出的材料：完整实验结果、主张—证据矩阵、统计表、边界与失败分析、可复现的补充材料。

完成标准：每项核心贡献均有真实证据；证据不足时补必要实验或收缩主张，不按预设结论挑选结果。

## 3.1 实验计划制定

来源编号：`prompt-17`

```text
请为我的论文制定一个最长【时间，例如2个月】的详细实验计划。

要求：
1. 精确到每天或每周要完成什么；
2. 列出实验器材、场景、物品、传感器、软件和数据记录表；
3. 每个实验说明目的、步骤、变量、评价指标、成功标准；
4. 包含对比实验、消融实验、鲁棒性实验和失败案例分析；
5. 给出数据整理、绘图和论文写作安排；
```

## 3.8 实验数据全文一致性审计

来源编号：`prompt-44`

```text
请对我提供的论文、CSV、日志、图表和实验记录进行全文一致性审计。

逐项核对：实验编号与场景、样本数量、成功/失败次数、成功率、均值、标准差、单位、时间、图例和方法名称。重新计算所有可验证的百分比与提升比例，并检查摘要、正文、表格、图注和结论是否一致。

输出：
1. 原始数据与计算过程；
2. 正确结果；
3. 所有矛盾位置；
4. 需要同步修改的文本、表格和图注；
5. 无法确认时需要补充的原始记录。

严禁选择性忽略失败数据或补造缺失数值。

投稿核心原则：讲好故事、做好证据。
请在本任务中检查“重要问题—现有缺口—关键洞察—方法—验证—贡献与边界”的主线是否连贯，并逐项对应核心主张及其真实证据。指出故事线断点、证据缺口和过度推断；给出具体修改或最小必要补充验证方案。没有证据支撑的结论应收缩或标为待验证，不得通过夸大表述、编造数据或隐瞒不利结果增强说服力。
```
