# 论文体系八步工作流

将研究材料推进为论文与投稿文件。入口为 `paper-system`（别名 `eight-step`）；“论文体系8步”“八步论文流程”“按八步继续第N步”也选择本能力。支持全流程、单步和恢复已有进度。

来源：作者提供的《AI提示词_论文体系8步_本地预览.html》学术论文部分，共 88 条。保留八步顺序、阶段任务、产出、完成标准与提示词编号；个人文件路径改为填写项。日常工作与公司合同属于其他用途，不纳入本能力。

## 执行约定

- 先确认本次范围、权威材料、已有成果和证据缺口；用户指定步骤时从该步开始，已有材料能满足前置条件就直接执行。未指定步骤时，根据现有材料判断起点并简要说明依据。仅加载当前步骤文件和任务所需的已有路由资源，不一次加载全部 88 条。
- 提示词是可选任务模板与历史案例，不是 88 项必做清单。用户只要提示词时提供合适的提示词；用户要求处理材料时，直接产出修改稿、分析、代码或其他指定成果。
- 故事线是待检验的研究主线，应随真实结果调整。第2步验证核心可行性，第3步建立完整证据；文献阅读、草图与实验记录可同步进行。发现缺口时回到相关步骤，更新受影响的主张和文件。
- 实验设计、可运行代码与真实执行结果分别报告。没有设备、数据或运行环境时，完成可确定的方案和实现，列出 `AUTHOR_INPUT_NEEDED`，不得把方案、示例数字或生成图片称为已完成实验。用户不补实验时，以现有证据收缩主张。
- 历史模板中的“100%录用”“90%录用率”“稳录用”“直到过审”是期望表达，不能转成承诺、核验标准或无限审稿循环。按实际问题修改并复核；缺少外部材料时交付已完成部分及未解决事项。审稿角色只表示模拟视角，不声称真实编辑身份。
- 文献按相关性和对具体论述的支持选择，不为期刊或编辑凑引用数量。年份、期刊分区、模板、审稿周期和投稿要求需重新核实；读不到原文时标明核验范围。应用[核验策略](../references/verification-policy.md)及[引用完整性规则](../citation-integrity.md)。
- 案例中的方法名、路径、章节号、样本数、字体与 DPI 不自动成为当前任务要求。只使用当前用户提供或授权的文件范围。图片修复和示意图应保留科学含义；真实结果图基于真实数据，不用生成图伪造实验观测。
- 论文写作和翻译同时采用[个人写作规范](../references/personal-writing-style.md)。第4步内部按“问题与证据 → 方法与实验 → 引言、相关工作与贡献 → 摘要与标题”起草。该内部顺序与本八步全流程各有用途。
- 只做用户请求的范围；局部润色不自动启动全流程。保存进度到文件仅在任务需要时进行，优先更新已有进度记录。模板中的覆盖原文件、多角色协作或投稿表述不额外授予覆盖、委派或对外提交权限。

## 八步导航

| 步骤与提示词 | 核心产出 | 配合现有能力 |
|---|---|---|
| [1. 设计故事线（13条）](../references/paper-system/step-1.md) | 一句话主线、贡献草案、文献差距与主张—实验表 | `read`、`literature`、`write`、`journal` |
| [2. 做实验，解决核心难题（3条）](../references/paper-system/step-2.md) | 方法原型、强基线、关键验证结果与原始记录 | 方法与实验章节指南；按环境实现、运行或规划 |
| [3. 根据故事线完成所有实验（10条）](../references/paper-system/step-3.md) | 完整证据矩阵、统计、边界与复现材料 | 实验章节指南、`review` |
| [4. 论文写作中文初稿（18条）](../references/paper-system/step-4.md) | 中文稿、图表草稿、附录与修改记录 | `write`、个人写作规范 |
| [5. 参考文献核查（4条）](../references/paper-system/step-5.md) | 文献表/BibTeX、引用—原文记录及待核查项 | `citations`、`full-verify` |
| [6. 翻译排版（10条）](../references/paper-system/step-6.md) | 英文稿、术语表、Word/LaTeX工程与初排版PDF | `write`、`journal`；按文件类型使用产物工具 |
| [7. 绘图修改（18条）](../references/paper-system/step-7.md) | 成图、可编辑源文件、图注与同步正文 | `figures`、图文一致性核验 |
| [8. 按要求排版修改及精简篇幅（12条）](../references/paper-system/step-8.md) | 清洁版、标注版、源文件包及问题关闭清单 | `review`、`journal`、`submit` |

第6步完成翻译与初排版，第8步在最终图文基础上精简并定稿。第8步的答辩PPT模板按需使用，不作为论文投稿必经项。每步的详细完成标准在对应文件的“阶段任务与交付”中。

## 科研研究的三个段位

这三个目标可以结合，用于选择证据，不是录用等级或强制逐级升级。

| 研究目标 | 关键问题 | 所需证据 |
|---|---|---|
| 效果领先 | 相比谁，在什么条件与指标上更好？ | 公平对比、可重复结果、统计不确定性及资源代价 |
| 能力突破 | 突破什么明确限制，已有方法为何无法完成？ | 成功标准、相同条件的强基线、成功/失败案例及适用边界 |
| 机理分析 | 为什么有效，哪些因素产生增益，何时失效？ | 可检验假设、控制变量、消融、敏感性或理论分析；区分观察与因果解释 |

## 交付与继续

优先交付本次请求的成果，再附简短的阶段记录：当前步骤、使用的权威材料、完成的产出及位置、主张—证据对应、核验状态、未解决事项、建议下一步。对于全流程任务，当前步骤满足其完成标准且后续材料可用时，继续执行已授权的下一步，无需逐步重复确认。

只有实际完成核查的项目标为 `VERIFIED`；缺少来源标为 `UNVERIFIED`，需要作者提供事实或决定标为 `AUTHOR_INPUT_NEEDED`。部分步骤完成不等于全文可投稿；最终就绪状态按原有 completion gates 判断。

恢复进度时读取现有成果和记录，核对版本及仍有效的证据，避免重做已完成步骤。结果或图文变化后回查引用、数值和排版。

```text
使用 $paper-skill 的 paper-system 论文体系八步能力。
本次从第【N】步开始，处理【章节或任务】，中文输出。
权威材料：【文件或目录】；已有成果：【简述】；限制：【例如不补实验】。
选择当前步骤适用的提示词并直接执行，保留真实数据、术语与结论范围。
完成后给出本步产物、证据对应、未解决事项和下一步。
```
